## 📦 Quick Download & Installation / Быстрая установка

1. Download **[`minecraft_availability-0.1.0-beta.jar`](minecraft_availability-0.1.0-beta.jar)** from this branch or from the `mods/` directory.
2. Place it into your Minecraft `mods` folder:
   * **Windows**: `%appdata%\.minecraft\mods`
   * **Linux**: `~/.minecraft/mods/`
   * **macOS**: `~/Library/Application Support/minecraft/mods/`
3. Ensure you have **Fabric Loader** (v0.16.0+) and **Fabric API** installed.
4. Launch the game and press **`Ctrl + Alt + S`** for settings or **`Ctrl + Alt + A`** to toggle speech.
