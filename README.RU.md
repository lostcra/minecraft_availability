# Minecraft Availability (Бета v0.1.0)
**Модификация доступности (Accessibility) для незрячих и слабовидящих игроков в Minecraft**

Добро пожаловать! Данная модификация разработана для того, чтобы сделать игру Minecraft (Java Edition) полностью доступной для незрячих и слабовидящих людей. Мод озвучивает интерфейсы, инвентарь, сундуки, достижения, чат, статистику и экран F3 с помощью речевых синтезаторов.

---

## 📋 Системные требования

* **Версия Minecraft**: Java Edition 26.3 (или совместимая версия 1.21+)
* **Загрузчик модов**: [Fabric Loader](https://fabricmc.net/) (версия 0.16.0 или новее)
* **Необходимые зависимости (скачиваются отдельно в папку mods)**:
  1. **Fabric API** — [Скачать на Modrinth / CurseForge](https://modrinth.com/mod/fabric-api) (для версии 26.3)
  2. **Cloth Config** *(рекомендуется для меню)* — [Скачать на Modrinth](https://modrinth.com/mod/cloth-config)

---

## 🚀 Пошаговая инструкция по установке

### 1. Предварительный шаг (если Fabric ещё не установлен)
1. Скачайте официальный установщик **Fabric Installer** с сайта [fabricmc.net](https://fabricmc.net/use/installer/).
2. Запустите его, выберите версию Minecraft (`26.3`) и нажмите кнопку **Установить (Install)**.
3. Откройте лаунчер Minecraft и убедитесь, что в списке версий появился профиль **Fabric Loader**.

---

### 2. Установка мода в игру

#### 🪟 Инструкция для Windows:
1. Скачайте файл **`minecraft_availability-0.1.0-beta.jar`** из этого релиза.
2. Нажмите комбинацию клавиш `Win + R` на клавиатуре.
3. В появившемся окне «Выполнить» вставьте следующий путь и нажмите **Enter**:
   ```
   %appdata%\.minecraft\mods
   ```
   *(Если папки `mods` ещё нет, создайте её вручную внутри `.minecraft`).*
4. Скопируйте в эту папку:
   * Файл мода `minecraft_availability-0.1.0-beta.jar`
   * Файл `fabric-api-....jar`
   * Файл `cloth-config-....jar`
5. Запустите лаунчер Minecraft и нажмите **Играть** под профилем Fabric.

#### 🐧 Инструкция для Linux:
1. Скачайте файл **`minecraft_availability-0.1.0-beta.jar`**.
2. Откройте терминал или файловый менеджер и перейдите в домашнюю директорию Minecraft:
   ```bash
   mkdir -p ~/.minecraft/mods
   cp minecraft_availability-0.1.0-beta.jar ~/.minecraft/mods/
   ```
3. Убедитесь, что там же находятся `fabric-api` и `cloth-config`.
4. Запустите игру через ваш лаунчер (Official, Prism Launcher, ATLauncher и др.).

#### 🍎 Инструкция для macOS:
1. Скачайте файл **`minecraft_availability-0.1.0-beta.jar`**.
2. В Finder нажмите сочетание клавиш `Cmd + Shift + G` (Переход к папке).
3. Введите путь:
   ```
   ~/Library/Application Support/minecraft/mods
   ```
   *(Если папки `mods` нет, создайте её).*
4. Поместите файл `minecraft_availability-0.1.0-beta.jar`, а также `fabric-api` в открывшуюся папку.
5. Запустите игру.

## 🎮 Управление и горячие клавиши

После входа в игру или в главное меню вам доступны следующие горячие клавиши:

| Комбинация | Действие |
| :--- | :--- |
| **`Ctrl + Alt + S`** | Открыть главное меню настроек доступности |
| **`Ctrl + Alt + A`** | Быстрое включение / выключение всей озвучки мода |
| **`Ctrl + Alt + C`** | Включение / выключение озвучки игрового чата |
| **`F3 + Пробел`** | Озвучить сводку F3 (координаты X, Y, Z, направление взгляда, биом, освещение) |
| **Любая клавиша** *(или Ctrl)* | Мгновенно прервать текущую речь (если включена опция прерывания) |

## 🎙️ Настройка синтезаторов речи

Мод умеет работать на любой операционной системе:

1. **Windows**:
   * По умолчанию используется **Windows SAPI** (системные русские и английские голоса Microsoft: Irina, Zira, David, а также SAPI 5 голоса RHVoice и eSpeak).
   * Вы также можете подключить внешние CLI-синтезаторы (**eSpeak NG**, **RHVoice**, **Piper**) в 1 клик с помощью кнопки **«Автопоиск»** во вкладке синтезаторов.
2. **Linux**:
   * По умолчанию используется встроенный **Mojang Narrator**.
   * Вы можете установить `espeak-ng` (`sudo apt install espeak-ng` или аналогичной командой в вашем дистрибутиве) и подключить его через кнопку «Автопоиск» или вручную указать `/usr/bin/espeak-ng`.
3. **macOS**:
   * Доступен встроенный **Mojang Narrator** и системный синтезатор `say` (`/usr/bin/say`).

## ❓ Возможные неполадки (FAQ)

* **Игра не запускается (краш при старте)**:
  * Проверьте, установлена ли Java 25.
  * Убедитесь, что в папке `mods` лежит подходящий `fabric-api` для версии Minecraft 26.3.
* **Нет звука / речи**:
  * Нажмите `Ctrl + Alt + A`, чтобы проверить, включена ли озвучка.
  * Нажмите `Ctrl + Alt + S`, перейдите на вкладку «Синтезатор» и нажмите кнопку **«Тест»**.
  * Если голос не звучит, выберите другой движок (например, **Mojang Narrator**).
* **Синтезатор читает слишком быстро или медленно**:
  * В меню `Ctrl + Alt + S` на вкладке «Речь» отрегулируйте ползунок «Скорость» от -10 до +10.
