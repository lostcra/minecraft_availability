# Minecraft Availability (Доступность в Minecraft)

Мод для Minecraft (Fabric Loader, версия 26.3), созданный специально для обеспечения полноценной доступности игры незрячим и слабовидящим пользователям.

---

## 🌟 Основные возможности

### 1. Горячие клавиши быстрого доступа
* **`Ctrl + Alt + A`** — глобальное включение и отключение озвучки игры с голосовым подтверждением («Озвучка включена» / «Озвучка отключена»).
* **`Ctrl + Alt + C`** — независимое включение и отключение чтения сообщений в игровом чате («Озвучивание чата включено» / «Озвучивание чата отключено»).
* **`Ctrl + Alt + S`** — открытие графического интерфейса настроек доступности.

---

### 2. Полная озвучка интерфейса
* **Озвучивание экранов и меню**: при открытии любого меню (главный экран, пауза, настройки, инвентарь и др.) мод автоматически произносит название текущего экрана.
* **Озвучивание элементов управления**: кнопки, переключатели, ползунки и текстовые поля озвучиваются при наведении и переключении фокуса с клавиатуры.

---

### 3. Доступность инвентаря и контейнеров
* **Озвучка слотов**: произносится номер слота, название предмета, количество предметов, а также информация о предмете, находящемся в руке (на курсоре).
* **Подробные подсказки**: чтение зачарований, прочности инструментов/брони, эффектов зелий и описания.
* **Клавиатурная навигация по инвентарю**:
  * **Стрелки `Влево` / `Вправо`**: переход к предыдущему / следующему слоту.
  * **Стрелки `Вверх` / `Вниз`**: переход между рядами инвентаря (шаг в 9 слотов).
  * **`Tab` / `Shift + Tab`**: циклическое переключение слотов.
  * **`Пробел` / `Enter`**: взять предмет или положить в выбранный слот с голосовым подтверждением («Взято: [предмет]», «Помещено: [предмет]»).
  * **`Shift + Пробел`**: быстрое перемещение предмета (Quick Move).
  * **Клавиша `R`**: повторить озвучку текущего слота.

---

### 4. Озвучка и навигация в меню достижений
* **Навигация по вкладкам**:
  * Клавиши **`Tab`** / **`Shift + Tab`** переключают вкладки достижений с автоматическим озвучиванием выбранной вкладки.
* **Клавишная навигация по дереву достижений**:
  * **Стрелка `Вправо`**: переход к дочернему достижению в ветке.
  * **Стрелка `Влево`**: возврат к родительскому достижению.
  * **Стрелки `Вверх` / `Вниз`**: переключение между соседними достижениями одной ветки.
* **Подробная озвучка каждого достижения**:
  * Название достижения.
  * Категория/тип: «Обычное», «Цель» или «Испытание».
  * Статус выполнения: «Выполнено» либо «Не выполнено» (с процентом прогресса при наличии требований).
  * Полное описание достижения.
  * **`Пробел` / `Enter`**: повторить озвучку выбранного достижения.

---

### 5. Синтезатор речи и гибкие настройки
* **Выбор движка TTS**:
  * `MOJANG`: встроенный диктор Minecraft (кроссплатформенный).
  * `WINDOWS_SAPI`: системный синтезатор Windows с поддержкой выбора установленных голосов (например, Microsoft Irina, Microsoft Zira, RHVoice и др.).
* **Выбор голоса**: выпадающий список доступных в операционной системе голосов.
* **Скорость речи**: регулировка от -10 до +10.
* **Громкость речи**: регулировка от 0 до 100%.
* **Проверка голоса**: кнопка тестирования синтезатора.
* Настройки сохраняются в конфигурационном файле `config/minecraft_availability.json`.

---

### 6. Клиентские команды
* `/accessibility` или `/mcaccess` — открыть окно настроек доступности.
* `/accessibility toggle` — переключить глобальную озвучку.
* `/accessibility chat` — переключить озвучивание чата.
* `/accessibility rate <-10..10>` — установить скорость речи.
* `/accessibility volume <0..100>` — установить громкость озвучки (в процентах).
* `/accessibility test` — произнести тестовое сообщение.

## 🛠️ Установка и сборка

### Установка
1. Установите [Fabric Loader](https://fabricmc.net/) для версии Minecraft **26.3**.
2. Поместите в папку `.minecraft/mods`:
   * `fabric-api.jar`
   * `cloth-config-fabric-26.3.159.jar` (для графического меню настроек)
   * `minecraft_availability-1.0.0.jar`
3. Запустите игру.

### Сборка из исходников
Для сборки с использованием установленной среды Java выполните PowerShell-скрипт:
```powershell
.\compile.ps1
```
Для одновременной сборки и копирования скомпилированного JAR-файла в папку модов Minecraft:
```powershell
.\compile.ps1 -InstallToMods
```
Файл собранного мода будет находиться в `build/libs/minecraft_availability-1.0.0.jar`.
