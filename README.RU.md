# Minecraft Availability (Доступность в Minecraft)

**Minecraft Availability** — это модификация для Minecraft (Fabric Loader, версия игры **26.3**), созданная специально для обеспечения полноценной, комфортной и независимой доступности игры незрячим и слабовидящим пользователям.

Мод превращает интерфейс Minecraft в полностью озвучиваемое рабочее пространство с поддержкой системных и сторонних синтезаторов речи, посимвольной навигации, звуковых сигналов и продуманного управления с клавиатуры.

---

## 🌟 Основные возможности

### 1. Горячие клавиши быстрого доступа
* **`Ctrl + Alt + A`** — глобальное включение и отключение озвучки игры с голосовым подтверждением.
* **`Ctrl + Alt + C`** — независимое включение/выключение озвучивания игрового чата.
* **`Ctrl + Alt + S`** — открытие графического меню настроек доступности.
* **`Ctrl + Alt + F`** (а также клавиша **`F3`**) — озвучивание координат, направления взгляда, биома, уровня освещения, целевого блока/существа и игрового дня.
* **Клавиша `Control`** (или **любая клавиша** при включении опции *«Остановка речи»*) — **мгновенная остановка текущей речи синтезатора** (стандартное поведение экранных дикторов NVDA/JAWS: позволяет прервать длинное чтение в любой момент).

---

### 2. Посимвольная навигация в полях ввода (`EditBox`)
Текстовые поля ввода в Minecraft теперь ведут себя как в полноценных текстовых редакторах с экранным диктором:
* **Стрелки `Влево` / `Вправо`**: перемещение курсора с озвучиванием конкретного символа. Знаки препинания и пути (`\`, `/`, `:`, `.`, `-`, `_`, пробел) озвучиваются понятными словами (*«обратный слэш»*, *«двоеточие»*, *«точка»*), что исключает ошибки при вводе путей.
* **Границы строки**: при достижении начала или конца озвучивается *«Начало строки»* или *«Конец строки»*.
* **`Ctrl + Влево` / `Ctrl + Вправо`**: перемещение по словам с зачитыванием текущего слова.
* **Стрелки `Вверх` / `Вниз`**: чтение всей строки целиком.
* **`Home` / `End`**: быстрый переход в начало или конец строки с озвучкой.
* **`Backspace` / `Delete`**: удаление символа с его проговариванием (*«Удалено: [символ]»*).
* **Ввод текста**: при наборе текста синтезатор сразу озвучивает введённую букву или символ.
* Полностью устранена проблема повторного чтения строки с самого начала при каждом нажатии стрелки.

---

### 3. Меню выбора голоса (`VoiceSelectionScreen`)
Кнопка выбора голоса в настройках открывает специальное меню со списком всех доступных в синтезаторе голосов:
* **Умная сортировка**: текущий выбранный голос отображается первым (с отметкой `✓`), русскоязычные голоса (`ru`, `russian`, `Aleksandr`, `Elena`, `Irina`) находятся в самом верху списка, за ними следуют английские и все остальные.
* **Поиск по названию и языку**: поле ввода позволяет мгновенно отфильтровать список (например, набрав `ru`, `en`, `Irina`, `David`).
* **Постраничная навигация**: клавиши `<< Пред.` и `След. >>` для удобного просмотра голосов.
* **Проверка на месте**: кнопка *«Проверить голос»* произносит пробную фразу выбранным голосом.

---

### 4. Подключение и автопоиск синтезаторов речи
Мод поддерживает три типа речевых движков:
1. **Windows SAPI (Системный)** — использует встроенные в Windows голоса (Microsoft Irina, Zira, David, а также SAPI 5 голоса RHVoice/eSpeak).
2. **Mojang Narrator** — встроенный диктор Minecraft.
3. **Пользовательские синтезаторы** (eSpeak, eSpeak NG, RHVoice, Piper и др.):
   * **Кнопка «Автопоиск»**: мгновенно сканирует реестр Windows (`HKLM/HKCU ... CurrentVersion\Uninstall`) и системные директории, находя установленные на компьютере синтезаторы речи в 1 клик без ручного ввода.
   * **Поддержка папок**: в поле ввода можно указать просто путь к папке программы (например, `C:\Program Files (x86)\eSpeak`). Мод сам найдёт нужный исполняемый файл внутри подпапок.
   * **Мастер установки**: если указан файл установщика (`setup.exe`), кнопка *«Установить...»* запустит установку, а после её завершения мод автоматически считает из реестра путь установки и подключит синтезатор.
   * **Кнопка «Обзор...»**: открывает стандартное окно проводника Windows для выбора файла.
   * **Защита от установщиков**: предотвращает случайный запуск файла `setup.exe` вместо программы при озвучке.

---

### 5. Дополнительные параметры речи
* **Остановка речи клавишами**: переключатель функции прерывания текущей речи любой клавишей клавиатуры.
* **Уровень пунктуации**:
  * *Выкл* — знаки препинания не читаются.
  * *Основная* — читаются точка, запятая, вопрос, восклицание, двоеточие.
  * *Все знаки* — читаются все спецсимволы (скобки, слэши, решётки, звёздочки и др.).
* **Чтение смайликов**: автоматический перевод текстовых смайликов (`:)`, `:D`, `XD`, `<3`, `¯\_(ツ)_/¯`) и эмодзи (😀, 😂, 🔥, ❤️, 👍 и др.) в русские слова.
* **Заглавные буквы**:
  * *Выкл* — без акцента.
  * *Слово* — произносит *«Заглавная [буква]»*.
  * *Тон* — повышение тона голоса на заглавных буквах (нативный параметр `-k 20` в eSpeak).
  * *Сигнал* — высокий звуковой щелчок при вводе или прохождении заглавной буквы.
* **Скорость и громкость**: плавные ползунки от -10 до +10 и от 0% до 100%.

---

### 6. Навигация по инвентарю и меню
* **Инвентарь**: навигация стрелками (`Влево/Вправо` — по слотам, `Вверх/Вниз` — по рядам на 9 слотов), взятие и перемещение на `Пробел/Enter`, `Shift + Пробел` для быстрого перемещения, `R` — повторить озвучку слота.
* **Достижения**: переключение вкладок клавишами `Tab / Shift+Tab`, навигация по дереву стрелками (`Вправо` — дочернее, `Влево` — родительское, `Вверх/Вниз` — соседние), зачитывание статуса и прогресса.
* **Меню F3**: озвучивание координат X Y Z, направления взгляда, биома, уровня освещения, блока и существа в прицеле, дня мира.

---

### 7. Команды чата
* `/accessibility` или `/mcaccess` — открыть окно настроек.
* `/accessibility toggle` — включить/выключить озвучку.
* `/accessibility chat` — включить/выключить чтение чата.
* `/accessibility rate <-10..10>` — установить скорость речи.
* `/accessibility volume <0..100>` — установить громкость речи.
* `/accessibility test` — произнести тестовое сообщение.

## 💻 Руководство для разработчиков (Architecture & Development)

### Структура проекта
Исходный код расположен в `src/main/java/com/github/lostcra/mcaccessibility`:
* **`config/`**:
  * `AccessibilityConfig.java` — модель конфигурации (сохраняется в `.minecraft/config/minecraft_availability.json`).
  * `AccessibilitySettingsScreen.java` — главное графическое меню настроек доступности.
  * `VoiceSelectionScreen.java` — экран поиска и выбора голосов с постраничной навигацией.
  * `AddSynthesizerScreen.java` — окно добавления стороннего синтезатора.
  * `SynthesizerFinder.java` — поиск установленных TTS через реестр Windows (`reg query`), сканирование папок и запуск установщиков.
* **`mixin/`**:
  * `MixinKeyboardHandler.java` — перехват горячих клавиш и прерывание речи по нажатию клавиш.
  * `MixinScreen.java` — озвучивание экранов и подавление избыточных повторов.
  * `MixinEditBox.java` — перехват ввода и перемещения курсора в текстовых полях.
  * `MixinAbstractContainerScreen.java` — доступность инвентаря и контейнеров.
  * `MixinAdvancementsScreen.java` — навигация по достижениям.
  * `MixinGameNarrator.java` — интеграция с подсистемой диктора Minecraft.
* **`navigation/`**:
  * `EditBoxNarrationHelper.java` — логика посимвольного чтения, слов, границ и удаления символов.
  * `InventoryNavigator.java` — логика перемещения по слотам инвентаря.
  * `AdvancementNavigator.java` — логика обхода дерева достижений.
  * `F3NarrationHelper.java` — сборка и озвучка сводки F3.
* **`tts/`**:
  * `SpeechEngine.java` — фасад речевой подсистемы, диспетчеризация между бэкендами.
  * `SpeechTextProcessor.java` — словарь эмодзи, смайликов и знаков препинания.
  * `WindowsSapiBackend.java` — бэкенд Windows SAPI через фоновый PowerShell/System.Speech.
  * `CustomCommandBackend.java` — бэкенд для внешних CLI-синтезаторов (eSpeak, RHVoice, Piper).
  * `MojangNarratorBackend.java` — fallback-бэкенд через ванильный диктор.

### Сборка проекта
Для сборки проекта используются кроссплатформенные скрипты с автоматическим обнаружением Java 25 и библиотек `.minecraft`:

**На Windows (PowerShell):**
```powershell
# Собрать JAR-файл мода (minecraft_availability-0.2.0-beta.jar):
.\compile.ps1

# Собрать и сразу установить в папку .minecraft/mods:
.\compile.ps1 -InstallToMods
```

**На Linux / macOS (Bash):**
```bash
# Собрать JAR-файл:
chmod +x ./compile.sh
./compile.sh

# Собрать и установить в папку mods:
./compile.sh --install
```
